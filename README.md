# Dynamic Gallery

A clean, responsive multi-column image gallery layout built using semantic HTML5 and CSS Flexbox.

## Features

* **Multi-Column Layout:** Organizes images into a structured 4-column layout using CSS Flexbox.
* **Fluid Image Scaling:** Images scale dynamically to fit their parent containers using `width: 100%`.
* **Clean & Lightweight:** Pure HTML and CSS with zero frameworks or external dependencies.
* **Easy Customization:** Flexible column and image structures that can be adjusted with CSS rules.
